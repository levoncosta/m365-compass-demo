# M365 Compass — Interactive Product Demo

A public, portfolio-safe demonstration of the M365 Compass workflow:

1. Assess
2. Validate
3. Recommend
4. Deliver

The demonstration uses fictional organization data and sample outputs. It does
not connect to a live Microsoft 365 tenant, process payments, or store client
information.

## Live demo

This repository is configured for GitHub Pages. The public site is available at:

https://levoncosta.github.io/m365-compass-demo/
